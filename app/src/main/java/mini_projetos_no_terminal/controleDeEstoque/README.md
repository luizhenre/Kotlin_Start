# 📦 Mini Projeto — Controle de Estoque em Kotlin

Este é um mini projeto em Kotlin que simula um sistema de controle de estoque via terminal.

O sistema permite:
- Consultar total de produtos
- Ver produtos em falta
- Ver produtos com baixa quantidade
- Atualizar o estoque
- Listar todos os produtos

---

## 🧠 Conceitos utilizados

Este projeto foi desenvolvido com foco em consolidar:

- Variáveis
- Arrays (`IntArray`)
- Funções com parâmetros e retorno
- Estruturas de repetição (`for`,`do while`)
- Estruturas de decisão (`if`, `when`)
- Entrada de dados via `readln()`

---

## 🗂 Estrutura do projeto

| Arquivo         | Função |
|-----------------|------|
| `Main.kt`       | Ponto de entrada do programa |
| `Utils.kt`      | Exibe o menu e controla a navegação |
| `Estoque.kt`    | Contém os dados e atualização de produtos |
| `Relatorios.kt` | Funções de cálculo e relatórios |

---

## ▶️ Como executar

Execute o arquivo `Main.kt`.  
O menu será exibido no terminal e você poderá interagir digitando as opções.
