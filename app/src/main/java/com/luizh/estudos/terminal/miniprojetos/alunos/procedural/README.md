# 📚 Sistema de Controle de Alunos (Kotlin)

Projeto em Kotlin desenvolvido para praticar **lógica de programação**, **funções**, **arrays**, **loops** e **organização de código**, simulando um sistema simples de controle de alunos via terminal.

---

## 🎯 Objetivo do Projeto

Criar um sistema em modo texto que permita:

- Listar alunos e suas notas
- Calcular a média da turma
- Consultar a situação de um aluno específico
- Atualizar a nota de um aluno
- Exibir um resumo geral de aprovados, recuperação e reprovados

O foco do projeto é **consolidar a base da linguagem Kotlin**, antes de avançar para Orientação a Objetos.

---

## 🧠 Conceitos Praticados

- Variáveis e tipos
- Funções com e sem retorno
- Arrays (`Array` e `DoubleArray`)
- Estruturas de repetição (`for`, `do while`)
- Estruturas condicionais (`if`, `when`)
- Validação de entradas do usuário
- Separação de responsabilidades por arquivo

---

## 🗂️ Estrutura do Projeto

### 📦 ControleDeAlunos

📜 Main.kt

📜 Dados.kt

📜 Relatorios.kt
 
📜 Utils.kt


### 📌 Descrição dos Arquivos

- **Main.kt**  
  Ponto de entrada do sistema. Responsável apenas por iniciar a aplicação.

- **Dados.kt**  
  Contém os arrays com os dados dos alunos e suas respectivas notas.

- **Relatorios.kt**  
  Responsável por todas as regras de negócio:
    - Listagem de alunos
    - Cálculo de média
    - Situação individual
    - Atualização de notas
    - Compilação do status geral da turma

- **Utils.kt**  
  Contém o menu interativo e o controle de navegação do sistema.

---

## 📋 Funcionalidades do Menu

1 - Listar alunos e notas

2 - Mostrar média da turma

3 - Mostrar situação de um 

4 - Atualizar nota de um aluno

5 - Mostrar quantidade de aprovados, recuperação e reprovados

---

## ▶️ Como Executar

1. Abra o projeto no **Android Studio** ou em um ambiente Kotlin
2. Execute o arquivo `Main.kt`
3. Interaja com o menu pelo terminal
